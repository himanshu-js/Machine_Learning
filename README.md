# Machine Learning 
It is a branch of Artificial Intelligence that deals with training, testing and implementation of 
machine 
In machine learning basically we train machine model to think and work like humans 

## Types
It has manly four types
1.Supervised Learning
2.Unsupervised  Learning
3.Semi - Supervised  Learning
4.Reinforcement  Learning

### Supervised Learning :
* In supervised learning you work as a teacher
* You provide input as well as output to the machine
* It is mostly used in machine learning
* Based on data it does the prediction
* It is further divided into two main models
* Classification - category, group
* Regression - relationship between Independent and dependent variable


### Unsupervised Learning :
* Input is given only
* Based on this input machine finds the pattern

### Reinforcement Learning :
* It works on trial and error
* receives positive points(reward) for good moves and negative points for mistakes
* Used in autonomous driving and teach robotics how to balance and walk


### Semi - Supervised Learning :
*  It combines a small amount of labeled data with a huge amount of unlabeled data during training.
*  Manual data labeling is expensive and slow; this method skips that bottleneck by letting the AI guess the labels of the remaining data based on the few examples it already knows
